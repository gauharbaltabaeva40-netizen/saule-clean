# Taza-Nur клининг сайты

GitHub репозиторийінің түбіріне архивтегі `dist` бумасын және `vercel.json` файлын жүктеңіз.

Vercel-де репозиторийді импорттағанда Framework Preset ретінде **Other** таңдаңыз. `vercel.json` статикалық сайттың дайын файлдары `dist` бумасында екенін көрсетеді.

Сайт орысша ашылады; жоғарғы жақтағы ауыстырғыш арқылы қазақша нұсқасын таңдауға болады.
